# mod_finder
Monster Hunter Wilds mod and audio replacement research

## 目录
- [mhwilds-longsword-sfx/](mhwilds-longsword-sfx/README.md)：《怪物猎人：荒野》太刀逐招式自定义音效调研，包括工具对比、逐招式粒度、操作流程、映射表模板和放置脚本。
- [mhwilds-catalog/](mhwilds-catalog/README.md)：荒野现成 mod 大全，共 599 个，覆盖太刀音效和语音、通用战斗音效、太刀玩法和外观、语音、BGM、其它音效和热门通用 mod，附冲突速查和 CSV。[精选推荐](mhwilds-catalog/PICKS.md)
- [tools/build_catalog.py](tools/build_catalog.py)：通过 Nexus 公开 API 重新生成上面的目录（`python tools/build_catalog.py --refresh`）。
