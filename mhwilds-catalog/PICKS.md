# 精选推荐（太刀玩家 / 音效方向）

这一页是从 [完整目录](README.md)（599 个 mod）里人工挑出来的。数据截至 2026-10-12，来源是 Nexus API。
“最后更新”晚于 2025-12-16（TU4）的标 ✅。没有 ✅ 的不代表不能用，但安装前请先看评论区。

## 5. 音频工具 / 能播放自定义音频的 mod
| 工具 | 说明 |
|---|---|
| [Sound Debugger](https://www.nexusmods.com/monsterhunterwilds/mods/3246) | 实时显示每个声音的 Event、WEM ID 和所在 bank。自己做太刀音效时用它查“哪一招是哪个 ID”，详见 [太刀音效调研](../mhwilds-longsword-sfx/README.md) |
| [MHWS Sound Tool](https://github.com/eigeen/mhws-sound-tool/releases) | 解包、回包 bank，按 ID 替换 wav、mp3 等。和上面的 Sound Debugger 搭配，就是自制逐招式音效的完整流程 |
| [StateMusic](https://www.nexusmods.com/monsterhunterwilds/mods/4628)（2026-10-02 ✅） | 把自己的 mp3、wav、ogg、flac 放进文件夹，按战斗状态、怪物、区域、低血量等自动切换 BGM。不改 bank |
| [Mute Some Lines](https://www.nexusmods.com/monsterhunterwilds/mods/1755) | 按台词、角色或音效 ID 静音或降低音量，在 REF 菜单里配置 |
| [Shut Up Nata](https://www.nexusmods.com/monsterhunterwilds/mods/1045) / [Shut Up Alma](https://www.nexusmods.com/monsterhunterwilds/mods/1202) | 减少或关闭 NPC 的唠叨语音 |
