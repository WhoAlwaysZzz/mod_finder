# 精选推荐（太刀玩家 / 音效方向）

这一页是从 [完整目录](README.md)（599 个 mod）里人工挑出来的。数据截至 2026-10-12，来源是 Nexus API。
“最后更新”晚于 2025-12-16（TU4）的标 ✅。没有 ✅ 的不代表不能用，但安装前请先看评论区。

## 1. 必装前置

| [REFramework](https://www.nexusmods.com/monsterhunterwilds/mods/93) | Nightly01240 / 2026-02-25 ✅ | 几乎所有 mod 的前置。进游戏按 Insert，勾选 Enable Loose File Loader。GitHub nightly 更新更快：[REFramework-nightly](https://github.com/praydog/REFramework-nightly/releases) |
| [CatLib](https://www.nexusmods.com/monsterhunterwilds/mods/65) | 1.14.0 / 2026-08-21 ✅ | 很多 REFramework 脚本类 mod 的公共库，Sound Debugger 也需要它 |
| [Fluffy Mod Manager](https://www.fluffyquack.com/) | — | 一键启用、禁用 mod。音效 mod 冲突时，切换起来最方便 |
